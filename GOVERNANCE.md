# Governance

The `scetrov` maintainer owns roadmap decisions, code review, merges, security triage and release approval at this pre-release stage. There is no elected committee, established response SLA, or delegated release authority. Contributions are considered on technical merit, safety, licensing and project scope; acceptance is not guaranteed. Significant changes should update the relevant OpenSpec proposal/spec/design before implementation. Feedback and disagreement should remain respectful and documented in the associated discussion or pull request.

When additional maintainers are appointed, update this file and CODEOWNERS with roles, decision-making rules, conflict resolution and a succession path. Repository settings, required reviews, signing enforcement and private security reporting must be confirmed on GitHub before being represented as active controls.
