# OpenSpec scenario-to-evidence review

Scope: all eight capability specs under `openspec/changes/establish-blender-pi-package/specs/` (48 requirements, 94 scenarios). Each row names **every** scenario for its requirement. Evidence is the nearest test, CI job, or documented review, not an assertion that an unrun release passed. Tests named below are run by `npm run validate`, `scripts/run_blender_smoke.py`, or the indicated workflow. GUI and publication gaps remain explicit. Reconcile this map after any spec edit and before archiving.
