# Secure use and artist control

Only pair a client whose displayed name, package version, working directory and trust request you recognize. **Full trust executes arbitrary Python in Blender with your user permissions; it is not sandboxed.** A same-user process or malicious add-on is outside pairing's effective boundary. For unknown projects, start with a disposable copy and inspection trust. Never paste a pairing code into a public issue or log; revoke trust in Blender after work.

Inspect the current file, active target, mode and selection before proposing a bounded mutation. Explain expected effects, risk and undo/checkpoint preferences. The bridge revalidates operation-scoped preconditions on Blender's main thread, including after approval. High-risk scene effects require a verified independent `.blend` checkpoint; obvious destructive external effects require artist approval with the known target or an honest unknown-target warning. Detectors are advisory and can miss aliases, add-on actions or dynamic Python. No absence of a warning proves safety; ordinary full-trust work does not trigger a blanket approval prompt.

During work, progress and cancellation are cooperative: caller request, bridge receipt and execution observation differ. Non-yielding Python or a native call can freeze Blender's UI; neither Pi nor the bridge safely force-kills arbitrary running code. An accepted operation may finish after disconnect. Re-pair and look up the exact operation ID and idempotency key; if unavailable, inspect the live file and decide explicitly before any retry. Do not assume a returned acceptance or restore request is final completion.

After a mutation, inspect the structured receipt and the live scene, use visual evidence when appearance matters, and preserve the artist's intent. Blender undo is not an external-filesystem rollback; a checkpoint restores `.blend` data, not overwritten exports, network activity, linked assets or external caches. Restore requires explicit artist confirmation and may lose unsaved work. See [recovery](recovery.md).

The bridge listens only on loopback and has no project-operated telemetry. Pi, your model provider and trusted code or add-ons can have different data paths; read [privacy](privacy.md) and the [threat model](threat-model.md). Report vulnerabilities through the private route in [SECURITY.md](../SECURITY.md), not a public issue. The first release is still blocked on [cross-platform validation](security-validation.md) and protected publishing settings.
