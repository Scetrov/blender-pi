# Support

This is an unreleased prototype. There is no supported production version, service commitment, guaranteed response time, or hosted support channel. The [README](README.md) describes what exists today and the [compatibility plan](docs/compatibility.md) describes intended platforms, not certified support.

When the GitHub repository is available, use issues for non-sensitive bug reports and feature requests, including Blender/Pi version, OS, reproduction steps and sanitized logs. Never post credentials or private scenes. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of a public issue. Blender itself and third-party add-ons have separate upstream support channels.
