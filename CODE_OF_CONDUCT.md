# Code of conduct

We expect respectful, constructive behavior in project discussions, reviews, and contributions. Be considerate of artists and developers with different experience levels; critique ideas and code, not people. Harassment, discrimination, threats, doxxing, sexualized attention, and deliberate disruption are not acceptable.

The maintainer may remove harmful content or restrict participation to protect the community. To report conduct concerns privately, use the [GitHub private vulnerability reporting route](SECURITY.md) only if it is enabled and explicitly accepts conduct reports; until a dedicated confidential conduct channel exists, contact the maintainer privately through an established channel rather than posting sensitive details publicly. This pre-release project does not yet promise a formal investigation timeline. Retaliation against reporters is prohibited.

The maintainer will seek context, respect confidentiality as far as practicable, and communicate a proportionate action. This project is establishing its reporting channels; do not claim a mature enforcement process where none exists.
